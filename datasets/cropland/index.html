    🏞️ Prairie Annual Cropland Mask and Frequency Surfaces

    Active Internal

    Overview

    Annual 10 m cropland mask products with frequency and stability summaries used as foundational layers for downstream analyses.

    Field Details
    Dataset ID NDAC-CROPLAND-007
    Category Land Cover / Base Layers
    Project Cropland Mask Prairies
    Owner NDAC / ACI Lab
    Primary Contact Thuan Ha

    Coverage
    Spatial Prairie region
    Temporal 2017-2024

    Data Contents

    Field Details
    Data types Raster masks, summaries, sample points
    Formats GEE asset, TIFF, CSV
    Status Processed / Active

    Notes: Contains annual masks, crop frequency, stable cropland layers, and stratified samples.

    Access

    This dataset is not directly downloadable

    This portal page describes the dataset so you can evaluate its relevance. Data files are held on NDAC infrastructure and are not publicly accessible through this portal.

    Access level: Internal summary view; direct access by request

    Interested users should contact NDAC to discuss purpose, permissions, and any project-specific conditions. Access decisions may depend on project scope, data sensitivity, partner agreements, and steward approval.

    To inquire about this dataset:
    Contact Thuan Ha or the NDAC Data Team
    📧 Thuan.ha@usask.ca
    Please include the dataset ID NDAC-CROPLAND-007 and a brief description of your intended use.
